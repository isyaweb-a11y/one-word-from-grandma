## The entry

`main.py` writes exactly one word to `/output/entry.txt` — the word a
grandma would text about AI:

> ALEXA

She talks to the smart speaker like a disobedient grandchild, and she
texts in all caps because that is how she texts everything.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
